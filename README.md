# KNIS Garage Web-App

Eine mobile Web-App/PWA für Fahrzeugdaten, Tankvorgänge, Ausgaben und Wartung. Daten werden lokal im Browser gespeichert (`localStorage`); Export als JSON.

## Lokal testen
Einfach `index.html` öffnen. Für Offline-Modus und PWA-Installation muss die App über HTTPS oder `localhost` ausgeliefert werden.

## Auf dem iPhone verwenden
1. Dateien auf einen HTTPS-Webhost hochladen (z. B. GitHub Pages).
2. Die HTTPS-Adresse in Safari am iPhone öffnen.
3. Teilen → **Zum Home-Bildschirm** → Hinzufügen.

Hinweis: Eine PWA kann nicht die nativen iOS-Home-Screen-Widgets der Swift-App bereitstellen. Diese Version enthält daher keine echten iOS-Widgets.
